# 末班渡轮

雾从江面一米一米漫上来。先湿的是跳板的铁链，再是林生的鞋面。挂在杆上的灯嗡嗡地亮着，光落在湿跳板上，照出一片白。

售票亭的窗口开着。桌上那沓船票磕得齐整，最上面一张没有日期，纸边被穿堂风翻起又落下。阿婆一只手按在票沓上，指节瘦，没有动。

林生的旅行袋带子勒在肩上。侧兜里那份文件夹的硬边硌着腿，从下午到现在，他没把它抽出来过。

他手里攥着一张旧船票，被雨泡软了，弯在指间。柴油味浮上来的时候，他想起小时候有人牵着他的手走过这块跳板。那时他没问要去哪儿。

“上不上？”阿婆问。

他没答。把票举到灯下看了看，又朝窗口晃了晃，嘴角扯出一点笑：“阿婆，这票泡成这样，还认吗？”

阿婆把手从票沓上抬起来，没去拿票，只把搪瓷杯往窗口边推了推，眼睛落在他攥票的那只手上。

“雾大，票攥那么紧，纸要烂的。”

过了一会儿，她又说：“我这儿的票，认纸不认日子。”

林生捏着票的手指反而更紧了。鞋跟还停在跳板边缘，半步之外。雾漫过跳板的一半，售票亭的灯嗡了一声，暗了半秒。两个人就着这半秒，谁也没动。

阿婆把搪瓷杯搁在窗台上，杯底磕出闷闷一声。她把票沓往旁边挪了挪，腾出窗台一角。

“站了这半刻，腿不酸？进来坐，船还得一会儿。”

林生没进去。把旅行袋换到另一只手上，往前挪了半步，鞋尖抵住跳板边缘，没踩上去。

“阿婆，我小时候坐这船，你多给我一颗糖。今天还有没有？”

阿婆看了他一眼，从柜台下摸出一只旧铁皮糖盒，推到窗口停着。盒盖上有几道被指甲刮过的锈痕。她没打开。林生也没再问。

他把湿票折了一道，塞进外套内兜。纸贴着胸口，凉。发动机在雾里一声接一声地转。

过了几分钟，阿婆拇指顶住盒盖，往上一掀。锈边磨出一声细响。里头几颗糖黏成一坨，泛着旧黄，糖纸褪了色。

“化了又干，不中用了。”她说。

林生笑了一下，笑到一半自己先收住了：“我小时候坐您的船，您还多给过一颗呢。”

阿婆没接这句。她把盒盖轻轻按回去，把糖盒推到窗台正中，离林生近了一指。

林生把手伸进内兜，摸出那支没拧开的笔，在指间转了一下。

“阿婆，您说这船——我要是上去了，是不是就没有回头的了？跟这签字笔一样，一拧开就合不上了。”

说完他自己先低了头，把笔攥回手心。对岸病房的灯也是这个颜色，白里发黄，整夜不关——这想法冒出来，他赶紧把它按回去。

阿婆看着他，过了一会儿，说：“船等人，不等笔。”

她没有再说别的。

雾里先多出一团比灯更白的光——船头的灯。隔着水汽只看得见一个毛边，慢慢变大一些，又停住。发动机不再一沉一提，转成一种低而匀的响。脚底下的木板跟着微微发麻。

阿婆把票沓最上面那张空白票抽出来，沿着窗台推过去，一直推到林生那侧。纸边悬在窗沿外。

“这张，没日子。你要走，就拿上；不走，就搁回来。”

她的手没有收，搭在票沓上，眼睛落在他攥笔的那只手上。

林生弯腰，把窗台上那只糖盒往阿婆那边推回半指。然后直起身，鞋尖探上跳板靠岸的那一截。

“阿婆，船靠了。我这一脚下去，可就真走了。”

他回头看了一眼。

窗口什么也没说。

阿婆的手仍压在票沓上，指节没有原先那么紧了。窗沿外那张空白票的边角被风掀起，落下，又掀起。

“雾里那个灯，你看见没有？”阿婆忽然开口，“船不急，我急——我就问一句，你是要走的，还是等人？”

林生把笔慢慢插回内兜。空出来的手在裤缝上蹭了一下。

“阿婆，您守了这么多年渡口……有没有谁上了船，又回来的？”

阿婆看了他一会儿。

“回来的，有。”她说，“多数是天亮了才回，夜里开的船，回来的少。”

她没有再说下去。林生也没再问。

他一只鞋尖压在跳板上，鞋底的水渍慢慢洇成一小片深色。内兜里那张湿票贴着胸口，笔在另一只手里，还没拧开。雾把跳板中段吃掉，只剩靠岸这一头还看得见铁锈和防滑纹。

*他一只鞋尖压在湿跳板上，船头灯在雾里亮着，阿婆那句“回来的少”落在两个人中间，谁也没再开口。*
